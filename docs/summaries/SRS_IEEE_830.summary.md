## Nội dung chính
- **Purpose/Scope**: ReConnect là nền tảng dCBT B2B2C (Mobile Patient + Web CMS Therapist/Admin + Spring Boot backend).
- **User classes**: Patient, Therapist, Clinic Admin.
- **Functional requirements**: mô tả theo module cho Mobile App, Web CMS, Admin/Background jobs.
- **Non-functional requirements**: security/privacy, performance, scalability/maintainability.
