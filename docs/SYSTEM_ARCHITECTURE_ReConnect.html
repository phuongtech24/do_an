TÀI LIỆU KIẾN TRÚC HỆ THỐNG VÀ THIẾT KẾ CSDL (SYSTEM ARCHITECTURE)

Dự án: Re-Connect Platform

1. Kiến trúc Tổng thể (Tech Stack)

Hệ thống Re-Connect đi theo mô hình Client-Server Service-Oriented Architecture (SOA):

  • Frontend (Mobile App): Flutter SDK (Dart) - Giao diện Bệnh nhân.
  • Frontend (Web CMS): Flutter Web / ReactJS - Giao diện Bác sĩ & Admin.
  • Backend: Java 17, Spring Boot 3.x, Spring Security (JWT), Spring Data JPA.
  • Cơ sở dữ liệu: PostgreSQL 15+ (Hỗ trợ tốt JSONB và khóa ngoại chặt chẽ).
  • Core AI Integration: API HTTP Call sang Google Gemini Pro (Text) và Google Cloud Vision (Image).

2. Thiết kế Cơ sở Dữ liệu Chi tiết (Database Schema)

Hệ thống xoay quanh 5 phân hệ lõi: Authentication, Profiles, Gamification (Quests), Medical Records (Tests/Logs), và Telehealth (Booking).
